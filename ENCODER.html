ENCODER — the CFM at a glance

One event stream in, one frozen self-supervised encoder out. The state is a continuous-time fade + tick, solved by an exact affine scan; the served object is a small set of named blocks that simple consumers read. This is a map of the architecture — not a measurement card.

The cell

Every event updates one state: hₜ = aₜhₜ₋₁ + (1−aₜ)Bxₜ, with aₜ = exp(−δₜΔt) and a learned per-channel δ. The scan is exact, mergeable and linear-time; there is no attention over raw history.

The timescales

The canonical model carries a 256-channel spectrum of learned timescales, initialized from the stream's measured gap/autocorrelation spectrum. The expert bank is the same memory idea in parallel; the readout stays a concatenation.

The served object

E = boundary(proj(h)) + counter, with a per-sample orthogonal boundary (Cayley, κ=1) and an anchored additive counter folded into the same width. Candidate statistic blocks append; they never replace the one composition.

The block bank

Mass (additive), shape (contractive), order (pair/signature), response (randomized action curve), value (level/quantiles), uncertainty (coverage). A block that exists in one path and not another is a bug — the one-composition law.
