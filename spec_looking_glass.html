1. Core Objective

1.1 The contract
Input a Canonical Event Stream (CESI) — time-ordered discrete events with an entity key, categorical tokens, continuous magnitudes, and (when present) randomized action arms, logged propensity, and protected attributes.
Output a frozen foundation model whose foundational embeddings $z_t$ support supervised, unsupervised, and reinforcement-learning (RL) heads — including white_queen (OPE certification) and red_king (counterfactual evaluation) — without altering the encoder weights.
Interface the foundational embedding $z_t$ (per entity, per time), exposed as read-only tables.
Mechanism self-supervised next-event prediction over a portfolio of distributional and temporal objectives — the means, not the product.
Product a latent manifold maintained by construction to satisfy strict intrinsic representation quality and verified against held-out + ground-truth gates before it is called healthy.

1.2 v1.0 Definition of Done

ID Layer Criterion Gate (how it is measured)
C1 Producer Ingestion & genericity any CESI stream runs end-to-end with no code changes; action arms / protected attributes discovered from schema; feature types auto-resolved
C2 Producer Autonomous training converges on the held-out self-supervised objective under a data+hardware-derived budget; no per-run tuning; stable step 0 → end (no false green)
C3 Producer Fail-fast governance halts with a receipt on tensor-health violation, rank/absorbing-state collapse, or a below-ceiling stream — refusing to emit a model
C4 Product Intrinsic quality the operationalized metrics (§4) pass their calibrated gates on ≥2 diverse streams, per capability (never one composite)
C5 Product Frozen-manifold signal frozen $z_t$ beats model-free baselines on every capability the stream carries, each with uncertainty
C6 Consumer Supervised head adapter on frozen embeddings passes its independent gate (beats raw; effect size + interval)
C7 Consumer Unsupervised head grounded structure recovered from frozen embeddings (segment recovery / cluster stability), gated
C8 Consumer RL head on a stream with randomized arms + logged propensity, an OPE/counterfactual adapter (white_queen / red_king) passes its gate (incremental counterfactual margin vs. logging, calibrated). The encoder must supply whatever this requires (§5, Components C & H)
C9 Consumer Universal donor E-vs-R-vs-E+R ablation on donor_embeddings under the production head: embeddings add unique signal, never materially worse than raw
C10 Identity Reproducibility semver-versioned (0.MAJOR.MINOR) + receipted (inputs / config / seed / git SHA); deterministic

Verdict law — there is no FAIL.

Verdict Meaning Allowed?
PASS the capability is carried by the stream and the model beats its baseline yes
NO_SIGNAL the stream provably cannot carry the target (certified by an independent stream-side entropy/identifiability ceiling, §3 Guardrail F) yes
FAIL the capability is carried but the model does not beat its baseline — a defect no — blocks v1.0

Every capability the stream can carry must PASS. NO_SIGNAL is never a relabeled failure.

2. Philosophy — Self-Governance

The system is autonomous, automatic, and self-governed: it resolves its own configuration from what it sees, derives its own budgets/thresholds/schedules from data + hardware, and fails fast with a receipt. Human input defines what quality means (the §1.2 criteria); the system decides how to reach it.

Principle Meaning
Invariants as native architecture isotropy, continuity, recurrence stability live in the state update and the optimization dynamics — never bolted on after a failure
Capacity over artificial constraints never shrink the model to make a gate pass; fix the objectives so the trunk uses its capacity
Truth-first diagnostics a capability that cannot be passed honestly is reported (FAIL / NO_SIGNAL), never hidden, weakened, or relabeled
Zero manual hyperparameters any surviving literal is a documented, overridable fallback, resolved at runtime and recorded in a receipt
Reproducibility is identity a change that can alter outputs bumps the version; every artifact records its inputs, config, and version
Adapt by construction an unseen schema / dim / horizon / action space must work with no code edits

4. Operational Definitions of the 12 Intrinsic Governance Metrics

Evaluated on frozen embedding checkpoints every $N$ steps; each is auditable and per-capability.

# Category Metric & definition Trigger / limit
1 Information Capacity & Fidelity Effective Rank Ratio $ER(Z) = \exp\left( -\sum_{i=1}^d p_i \log p_i \right)$, $p_i = \frac{\sigma_i}{\sum_{j=1}^d \sigma_j}$ halt if $ER(Z_{current}) / ER(Z_{baseline}) < 0.15$
2 Geometric Separability & Manifold Health Alignment & Uniformity: $\mathcal{L}_{align} = \mathbb{E}_{(z, z^+) \sim p_{pos}} \left[ \Vert{} z - z^+ \Vert{}_2^2 \right]$, $\mathcal{L}_{uniform} = \log \mathbb{E}_{z, z' \sim p_{data}} \left[ e^{-2 \Vert{} z - z' \Vert{}_2^2} \right]$ align ↓, uniformity ↓
3 Temporal Coherence & Markovianity Time’s Arrow Asymmetry $TAA = \mathbb{E}\left[ \Vert{} z_{t+1} - f_{fwd}(z_t) \Vert{}_2^2 \right] - \mathbb{E}\left[ \Vert{} z_t - f_{bwd}(z_{t+1}) \Vert{}_2^2 \right]$ $TAA > 0$ (arrow of time respected)
4 Disentanglement & Factorization Total Correlation $TC(Z) = D_{KL}\left( q(z) \;\Big\Vert{}\; \prod_{j=1}^d q(z_j) \right)$ independence across latent blocks
5 Robustness & Nuisance Invariance Augmentation Invariance Distance $\mathcal{L}_{inv} = \mathbb{E}\left[ \Vert{} f(x) - f(x_{augmented}) \Vert{}_2^2 \right]$ low
6 Epistemic Density & Boundary Awareness OOD AUROC from Mahalanobis $D_M(z) = \sqrt{(z - \mu)^T \Sigma^{-1} (z - \mu)}$ AUROC separation of in-dist vs noise $> 0.5$
7 Equivariance & Group Symmetries (conditional) Equivariance Error $\mathcal{L}_{eq} = \mathbb{E}\left[ \Vert{} f(g \cdot x) - g' \cdot f(x) \Vert{}_2^2 \right]$ low
8 Manifold Flatness & Interpolation Validity Geodesic Interpolation Loss $\mathcal{L}_{geo} = \mathbb{E}_{\alpha \in [0,1]} \left[ \Vert{} f(\alpha x_i + (1-\alpha)x_j) - (\alpha f(x_i) + (1-\alpha)f(x_j)) \Vert{}_2^2 \right]$ halt on interpolation-error spike past local tolerance
9 Causal Identifiability (conditional) Interventional Shift Variance $ISV = \text{Var}\left( z_{t+1} \mid do(a_t) \right) - \text{Var}\left( z_{t+1} \mid a_t \right)$ $ISV > 0$
10 Controllability & Reachability (conditional) Reachability Gramian rank $\sigma_{\min}(W_R) \ge \epsilon$, $W_R = \sum_{k=0}^{K} A^k B B^T (A^T)^k$ $\sigma_{\min}(W_R) \ge \epsilon$
11 Temporal Hierarchy & Abstraction Temporal Abstraction Decay Ratio $TAR = \frac{I(Z_{macro}; x_{t+k})}{I(z_t; x_{t+k})}$ for $k \gg 1$ abstraction gain at long horizon
12 Protected Attribute Invariance (conditional) Null-Space Residual $NSR = 1 - \text{Accuracy}\left( \text{Decoder}(P_{\text{null}} z_t) \to S_{\text{protected}} \right)$ halt if residual decoding exceeds chance

9. Structured Capability Model (the macro HOW)

This section is the working bridge between the target (§4–§5) and the as-built (§8). It defines, structurally, why a capability succeeds and where to act when it does not. We evolve this section as the macro architecture and the probe harness change — it is the model that tells us what to build next rather than chasing one failure at a time.

9.1 The capability success law

For a capability c on a stream s, with z_t the frozen foundational embedding, define four predicates:

PredicateMeaningMeasured by
CARRIED(s,c)the stream carries the signalindependent stream-side ceiling (§3-F): a model-free ceiling predictor beats the trivial baseline by > noise
PRESERVED(z,c)the contractive core retains the signal through the mixeroracle probe on the pre-readout hidden state H_t beats the baseline
EXPOSED(z,c)z_t surfaces the signal to a probeprobe on z_t beats the baseline
BEATS(z,c)the model (frozen z_t) beats the model-free baselinecapability probe, margin > 2·SE

PASS ⇔ CARRIED ∧ PRESERVED ∧ EXPOSED ∧ BEATS.
NO_SIGNAL ⇔ ¬CARRIED (certified before compute).
FAIL ⇔ CARRIED ∧ ¬(PRESERVED ∧ EXPOSED ∧ BEATS).

The law localises a failure and dictates the fix — the macro decision procedure:

FailureDiagnosisMacro action
¬CARRIEDstream cannot carry the targetcertify NO_SIGNAL (stream-side ceiling, no compute)
CARRIED ∧ ¬PRESERVEDthe recurrent core destroys the signalcore change: add/repair the channel or timescale that retains it (Component A/B)
CARRIED ∧ PRESERVED ∧ ¬EXPOSEDthe readout does not surface itreadout change: a bypass channel for that capability’s input (Component A, Payload Bypass)
CARRIED ∧ PRESERVED ∧ EXPOSED ∧ ¬BEATSinformation is present but the head does not use ithead/objective change: dedicated head, convergence, de-sharing — never a loss hack

Worked examples from the record: next was CARRIED (1-gram beats marginal, MI≈0.05) but ¬EXPOSED (the recurrent readout washed the event identity out) — fixed by the event-identity bypass, not by tuning. entity is ¬CARRIED on ecommerce (entity_type is the constant "product") → NO_SIGNAL. uncertainty is EXPOSED but ¬BEATS (derived entropy AUROC 0.500) → objective change or NO_SIGNAL.

9.5 Build dependency graph (what unblocks what)

  1. Stream-side identifiability ceiling (§3-F) — prerequisite for the whole no-FAIL law: certifies ¬CARRIED (NO_SIGNAL) before compute and retires FAIL_LOW_EFFECT_SIZE. Unblocks C2–C5.
  2. Payload Bypass Stream (Component A) — the general EXPOSED mechanism; event-id bypass (DEC-057) proves it fixes next; extend to magnitude (fixes value/dt) and entity-id. Unblocks C4/C5.
  3. Core PRESERVED check — an oracle probe on H_t to separate ¬PRESERVED from ¬EXPOSED (so we fix the right stage). Unblocks diagnosis.
  4. Action-conditioned operators (C&H) — required for C8 (RL, white_queen/red_king); testable on rabbit_hole only. Unblocks C8.
  5. Memory-bank Barlow (D) — anti-collapse decorrelation over an asynchronous queue (train-time; frozen per-sample at serve). Unblocks C3/C4.
  6. Composite uncertainty (E), macro-pooling (F), fairness null-space (G) — capability additions gated on a measured spike.
  7. 12-metric governance loop (§4) — operationalise the intrinsic metrics with calibrated (derived) thresholds and the halt rules.

Sequencing: 1 → 2 → 3 resolve the current FAILs honestly (PASS or certified NO_SIGNAL) and make the verdict law real; then 4 (C8, the RL requirement) and 5–7 deepen the manifold. Each step is promoted only when a measured spike beats the current mechanism (prefer deletion over accretion).
