Specification 0.9.3: The Geometric Manifold Foundation Model

1. Core Objective & Philosophy: The Canonical Telemetry Foundation Model Factory

The Grand Vision (The WHAT and the WHY)

The objective is to build an autonomous, self-governed foundation model factory that ingests Canonical Event Streams (CESI)—structured temporal telemetry, user clickstreams, and system logs—and automatically yields a production-grade foundation model.

The core philosophy remains: predicting the next event is merely a mechanism for constructing a latent manifold $z_t$ guaranteed to satisfy strict intrinsic representation quality. When the manifold is geometrically healthy, it natively powers supervised, unsupervised, and reinforcement learning (RL) downstream heads out-of-the-box without altering the core encoder weights.

Scoped Target Domain (0.9.3 Initial Release)

  • Target Domain: Time-ordered, discrete-event telemetry and transactional logs adhering to the Canonical Event Stream Interface (CESI).
  • Exclusions: Unstructured video, raw audio, and free-form text are out of scope for this architecture (delegated to modality-specific front-ends).

2. Mandatory Architectural Guardrails (The Invariants)

To achieve true autonomy and eliminate manual tuning, the architecture enforces the following structural laws by construction:

  • Guardrail A (Normalization by Construction): Per-sample feature normalization ($\sigma \approx 1.0$) applied exclusively within hidden recurrent mixer boundaries. Raw magnitude and trend data are preserved via the Payload Bypass Stream.
  • Guardrail B (Fail-Fast Tensor Health): Step-0 validation harness halting on NaN, Inf, explosive magnitude ($> 10^4$), or variance collapse ($\sigma^2 < 10^{-6}$).
  • Guardrail C (Bounded Operator Dynamics): Contractive state-space transitions ($\rho < 1$) enforced by spectral normalization on transition matrix $A$.
  • Guardrail D (Zero Supervised Loss Hacks): Absolute ban on focal loss, class weights, and manual auxiliary task balancing. Self-supervised representation objectives (e.g., Barlow Twins, predictive coding) are permitted as structural geometry constraints.
  • Guardrail E (Anti-Collapse): Prevention of low-rank degeneracy via asynchronous memory-bank decorrelation.
  • Guardrail F (Identifiability Ceiling): Grading data streams against pre-training information entropy ceilings before committing compute.
  • Guardrail G (Strict Causal Arrow Enforcement): Zero look-ahead leakage across temporal mixing layers (strictly causal masking).
  • Guardrail H (Absorbing State Prevention): Minimum singular value floor ($\sigma_{\min}(A) \ge \epsilon = 10^{-4}$) on recurrent operators.
  • Guardrail I (Information-Theoretic Invertibility Bound): Mutual information lower bound ensuring the encoder retains input entropy above a defined threshold ($I(x_t; z_t) \ge H_{min}$).

3. Operational Definitions of the 12 Intrinsic Governance Metrics

To make the governance loop mathematically auditable, all 12 macro categories are operationalized into concrete quantitative metrics evaluated on frozen embedding checkpoints every $N$ steps:

  1. Information Capacity & Fidelity (Effective Rank Ratio): $$ER(Z) = \exp\left( -\sum_{i=1}^d p_i \log p_i \right), \quad p_i = \frac{\sigma_i}{\sum_{j=1}^d \sigma_j}$$ Halt if relative effective rank $ER(Z_{current}) / ER(Z_{baseline}) < 0.15$.
  2. Geometric Separability & Manifold Health (Alignment & Uniformity): $$\mathcal{L}_{align} = \mathbb{E}_{(z, z^+) \sim p_{pos}} \left[ \Vert{} z - z^+ \Vert{}_2^2 \right], \quad \mathcal{L}_{uniform} = \log \mathbb{E}_{z, z' \sim p_{data}} \left[ e^{-2 \Vert{} z - z' \Vert{}_2^2} \right]$$
  3. Temporal Coherence & Markovianity (Time’s Arrow Asymmetry): $$TAA = \mathbb{E}\left[ \Vert{} z_{t+1} - f_{fwd}(z_t) \Vert{}_2^2 \right] - \mathbb{E}\left[ \Vert{} z_t - f_{bwd}(z_{t+1}) \Vert{}_2^2 \right]$$ Quantifies compliance with the arrow of time ($TAA > 0$).
  4. Disentanglement & Factorization (Total Correlation): $$TC(Z) = D_{KL}\left( q(z) \;\Big\Vert{}\; \prod_{j=1}^d q(z_j) \right)$$ Measures independence across latent subspace blocks.
  5. Robustness & Nuisance Invariance (Augmentation Invariance Distance): $$\mathcal{L}_{inv} = \mathbb{E}\left[ \Vert{} f(x) - f(x_{augmented}) \Vert{}_2^2 \right]$$
  6. Epistemic Density & Boundary Awareness (OOD AUROC): $$D_M(z) = \sqrt{(z - \mu)^T \Sigma^{-1} (z - \mu)}$$ Uses Mahalanobis distance $D_M(z)$ to compute AUROC separation between in-distribution and synthetic noise samples.
  7. Equivariance & Group Symmetries (Equivariance Error - Conditional): $$\mathcal{L}_{eq} = \mathbb{E}\left[ \Vert{} f(g \cdot x) - g' \cdot f(x) \Vert{}_2^2 \right]$$
  8. Manifold Flatness & Interpolation Validity (Geodesic Interpolation Loss): $$\mathcal{L}_{geo} = \mathbb{E}_{\alpha \in [0,1]} \left[ \Vert{} f(\alpha x_i + (1-\alpha)x_j) - (\alpha f(x_i) + (1-\alpha)f(x_j)) \Vert{}_2^2 \right]$$ Halt if interpolation error spikes past local tolerance threshold.
  9. Causal Identifiability (Interventional Shift Variance - Conditional): $$ISV = \text{Var}\left( z_{t+1} \mid do(a_t) \right) - \text{Var}\left( z_{t+1} \mid a_t \right)$$
  10. Controllability & Reachability (Reachability Gramian Rank - Conditional): $$\sigma_{\min}(W_R) \ge \epsilon, \quad W_R = \sum_{k=0}^{K} A^k B B^T (A^T)^k$$
  11. Temporal Hierarchy & Abstraction (Temporal Abstraction Decay Ratio): $$TAR = \frac{I(Z_{macro}; x_{t+k})}{I(z_t; x_{t+k})} \quad \text{for } k \gg 1$$
  12. Protected Attribute Invariance (Null-Space Residual - Conditional): $$NSR = 1 - \text{Accuracy}\left( \text{Decoder}(P_{\text{null}} z_t) \to S_{\text{protected}} \right)$$ Halt if residual decoding accuracy exceeds chance performance.

4. Architectural Components

  • Component 0 (Canonical Ingestion Interface): Validates incoming streams against the CESI schema contract (Timestamp, Entity ID, Categorical Tokens, Continuous Metrics). Proves presence/absence of optional action arms or protected attributes.
  • Component A (Multi-Scale SSM + Payload Bypass): Log-spaced decay spectrum ($\rho \in [0.05, 0.82]$) coupled with a raw payload bypass stream routed directly to readout.
  • Component B (Soft-Orthogonal Subspace Routing): Block-diagonal state transition matrix $A = \text{diag}(A_1, A_2, \dots, A_k)$ with regularized cross-talk penalties.
  • Component C & H (Conditional Action-Gated Operators & Rollouts): Opt-in. Dynamically instantiates $B(a_t)$ if action arms exist, enforcing bounded norm $\Vert{}B(a_t)\Vert{} \le \kappa$ to maintain contractivity.
  • Component D (Memory-Bank Barlow Alignment): Anti-collapse decorrelation loss computed over asynchronous rolling queue $Z_{mem}$, eliminating batch statistics (Guardrail A).
  • Component E (Composite Uncertainty): Structural uncertainty derived from reconstruction dispersion, Mahalanobis distance, and fast/slow temporal channel disagreement.
  • Component F (Boundary-Gated Soft-Macro-Pooling): Temperature-scaled soft-reset EMA session tracking ($Z_{macro}$).
  • Component G (Conditional Null-Space Fairness): Opt-in. Projects final vector onto orthogonal complement of protected attributes when declared in CESI schema.

5. The Two-Phase Factory Pipeline & Evaluation Plan

Phase 1: Self-Supervised Foundation Pre-Training

  • Encoder is trained via self-supervised predictive coding ($\mathcal{L}_{pred}$) and memory-bank Barlow decorrelation ($\mathcal{L}_{barlow}$).
  • Continuous execution of Step-1 Governance Loop with fail-fast Halt Rules.

Phase 2: Frozen-Manifold Downstream Probing

  • Encoder weights are permanently locked ($z_t = \text{Encoder}(x_{1:t})$).
  • Lightweight Supervised, Unsupervised, and RL heads attach as downstream adapters.

6. Execution Directive & Implementation Blueprint

Evolving architecture to Specification 0.9.3:

5. Enforce Halt Rules for Relative Effective Rank (< 0.15), Geodesic Interpolation Loss spikes, and Null-Space Leakage.

7.6 Gap analysis — what 0.9.3 requires that does not exist

  1. CESI capability discovery (§4-0): no declaration/parse of optional action arms or protected attributes.
  2. Barlow-Twins memory-bank loss (§4-D, §5 Phase 1 $\mathcal{L}_{barlow}$): only a geometry governor + structural bilinear rank; soft decorrelation was deliberately removed (DEC-044). Reintroducing Barlow must clear the doctrine ban on batch-coupled statistics (frozen transform at serve).
  3. Composite uncertainty (§4-E): needs reconstruction dispersion + Mahalanobis + fast/slow disagreement, wired to a calibrated interval.
  4. Macro-state pooling (§3-11, §4-F): Z_macro with a soft, differentiable boundary gate (the boundary signal is weak on ecommerce, AUROC 0.669).
  5. Causal action conditioning (§4-C/H, §3-9/10): only meaningful on randomized streams (rabbit_hole has arms; ecommerce is observational).
  6. Fairness null-space (§4-G, §3-12): absent.
  7. Governance loop for all 12 metrics (§3, §6-4): the current loop grades structure-skill + 5 intrinsic proofs, not the 0.9.3 metric set; halts exist for divergence/degeneracy, not for ER ratio < 0.15 / geodesic-spike / NSR leakage.
  8. Geodesic / equivariance / TAA estimators (§3-3, 7, 8): not implemented.

7.7 Doctrine reconciliation (why 0.9.3 must not regress the repo laws)

The 0.9.3 language ("spectral normalization", "Barlow Twins", "macro pooling") is compatible with AGENTS.md only if implemented under the existing laws:

  • No magic numbers → 0.9.3's literals ($10^4$, $10^{-6}$, $10^{-4}$, thresholds 0.15) must become derived/calibrated fallbacks with receipts.
  • No batch-coupled statistics (root AGENTS §0.6.0 / DEC-036) → any Barlow/ZCA path must be a frozen per-sample transform at serve time; batch-fit was measured to manufacture rank and is banned (V7_RFC §8.2).
  • Invariants by construction, not soft penalties (DEC-042/044) → prefer structural mechanisms (decay=exp(−softplus), bilinear rank, bounded gates) over loss terms; DEC-044 condemned soft loss-invariants.
  • Gate on ground truth, never weaken gates → failing ecommerce gates stand as honest LOW_EFFECT_SIZE / NO_IDENTIFIABLE_SIGNAL verdicts.
  • Prefer deletion over accretion → promote a 0.9.3 component only when a measured spike beats the current mechanism; otherwise keep the smaller system.
