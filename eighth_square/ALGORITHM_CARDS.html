Algorithm Summary Cards

Generation 0 — Roots

epsilon_greedy_bandit

  • Lineage: root (bandits)
  • Concept: Pull the arm with the best average reward so far, except with probability ε.
  • Idea added: learn action values from rewards; explore by random ε.
$$
Q(a) \leftarrow Q(a) + \alpha\big(r - Q(a)\big), \qquad
\pi(a) = \begin{cases} 1 - \varepsilon + \varepsilon/n & a = \arg\max_{a'} Q(a') \\ \varepsilon/n & \text{otherwise} \end{cases}
$$

policy_evaluation

  • Lineage: root (DP)
  • Concept: Compute a fixed policy's value by iterating the Bellman backup over a known model.
  • Idea added: repeated Bellman backup over the model's transition table.
$$
V_{k+1}(s) = \sum_a \pi(a|s) \sum_{s'} p(s'|s,a)\big[r + \gamma V_k(s')\big]
$$

mc_prediction

  • Lineage: root (MC)
  • Concept: Estimate values by averaging the full returns of complete episodes.
  • Idea added: average full-episode returns for visited states.
$$
V(s) \leftarrow V(s) + \alpha\big(G_t - V(s)\big), \qquad
G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
$$

td0_prediction

  • Lineage: root (TD)
  • Concept: Learn values from single transitions by bootstrapping off the next state's estimate.
  • Idea added: bootstrap the value from the next state's estimate.
$$
V(s) \leftarrow V(s) + \alpha\big(r + \gamma V(s') - V(s)\big)
$$

reinforce

  • Lineage: root (policy gradient)
  • Concept: A direct policy gradient: nudge the actions that led to good returns.
  • Idea added: the policy gradient theorem — ascend \(\nabla J\) directly.
$$
\nabla_\theta J(\theta) = \mathbb{E}_\pi\big[\nabla_\theta \log \pi_\theta(a|s)\, G_t\big]
$$

Generation 1 — First Children

optimistic_bandit

  • Lineage: epsilon_greedy_bandit → optimistic_bandit
  • Concept: Start every arm optimistically high so the agent explores until proven wrong.
  • Idea added: optimistic initialization — explore by being wrong.
$$
Q_0(a) \gg 0 \ \forall a, \qquad Q(a) \leftarrow Q(a) + \alpha\big(r - Q(a)\big)
$$

ucb_bandit

  • Lineage: epsilon_greedy_bandit → ucb_bandit
  • Concept: Score arms by value plus uncertainty — the undercounted get explored automatically.
  • Idea added: uncertainty bonus instead of ε.
$$
a_t = \arg\max_a\Big[Q(a) + c\sqrt{\frac{\ln t}{N(a)}}\Big]
$$

gradient_bandit

  • Lineage: epsilon_greedy_bandit → gradient_bandit
  • Concept: Learn softmax action preferences by gradient ascent instead of storing values.
  • Idea added: softmax preferences + baseline — the policy-gradient idea in miniature.
$$
H(a) \leftarrow H(a) + \alpha (r - \bar r)\big(\mathbb{1}\{a = A_t\} - \pi(a)\big), \qquad
\pi(a) = \frac{e^{H(a)}}{\sum_{a'} e^{H(a')}}
$$

thompson_sampling

  • Lineage: epsilon_greedy_bandit → thompson_sampling
  • Concept: Treat each arm's mean as a posterior distribution and sample from it — explore by random draw.
  • Idea added: sample actions from a Bayesian posterior.
$$
\theta_a \sim \mathrm{Beta}(\alpha_a, \beta_a) \ \text{per arm}, \qquad a_t = \arg\max_a \theta_a
$$

policy_iteration

  • Lineage: policy_evaluation → policy_iteration
  • Concept: Alternate full policy evaluation with greedy improvement until the policy stops changing.
  • Idea added: greedy improvement after each evaluation pass.
$$
\pi'(s) = \arg\max_a \sum_{s'} p(s'|s,a)\big[r + \gamma V^{\pi}(s')\big]
$$

value_iteration

  • Lineage: policy_iteration → value_iteration
  • Concept: Squeeze evaluation and improvement into a single in-place max-backup.
  • Idea added: fuse evaluation + improvement into one Bellman optimality backup.
$$
V(s) \leftarrow \max_a \sum_{s'} p(s'|s,a)\big[r + \gamma V(s')\big]
$$

mc_control_onpolicy

  • Lineage: mc_prediction → mc_control_onpolicy
  • Concept: Learn action values from episode returns, improving an ε-soft policy between episodes.
  • Idea added: learn Q under an ε-soft policy, improve between episodes.
$$
Q(s,a) \leftarrow Q(s,a) + \alpha\big(G_t - Q(s,a)\big), \qquad \text{ε-soft improvement: } \pi \leftarrow \varepsilon\text{-greedy}(Q)
$$

mc_control_offpolicy

  • Lineage: mc_prediction → mc_control_offpolicy
  • Concept: Learn the greedy policy from episodes played by another policy, reweighted by importance sampling.
  • Idea added: importance sampling to the greedy target policy.
$$
Q(s,a) \leftarrow Q(s,a) + \alpha\,\rho_{t+1}\big(G_t - Q(s,a)\big), \qquad
\rho = \frac{\pi(a|s)}{b(a|s)}
$$

sarsa

  • Lineage: td0_prediction → sarsa
  • Concept: Learn on-policy action values by bootstrapping from the next state-action pair.
  • Idea added: on-policy control — bootstrap with the next action actually taken.
$$
Q(s,a) \leftarrow Q(s,a) + \alpha\big(r + \gamma Q(s',a') - Q(s,a)\big)
$$

qlearning

  • Lineage: td0_prediction → qlearning
  • Concept: Learn the optimal action values directly by bootstrapping from the best next action.
  • Idea added: off-policy control — bootstrap with the max next action.
$$
Q(s,a) \leftarrow Q(s,a) + \alpha\big(r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big)
$$

Generation 2 — Refinements of TD Control

expected_sarsa

  • Lineage: sarsa → expected_sarsa
  • Concept: SARSA with the expected next value instead of the sampled one — variance reduction for free.
  • Idea added: expectation target — variance reduction.
$$
Q(s,a) \leftarrow Q(s,a) + \alpha\Big(r + \gamma \sum_{a'} \pi(a'|s') Q(s',a') - Q(s,a)\Big)
$$

nstep_sarsa

  • Lineage: sarsa → nstep_sarsa
  • Concept: Dial the bootstrap horizon: wait n steps before trusting the estimate.
  • Idea added: wait n steps before bootstrapping.
$$
G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n Q(S_{t+n}, A_{t+n})
$$

nstep_expected_sarsa

  • Lineage: nstep_sarsa → nstep_expected_sarsa
  • Concept: n-step returns with an expectation bootstrap at the end.
  • Idea added: n-step returns with expected-value bootstrapping.
$$
G_t^{(n)} = \sum_{k=1}^{n} \gamma^{k-1} R_{t+k} + \gamma^n \sum_{a'} \pi(a'|S_{t+n}) Q(S_{t+n}, a')
$$

tree_backup

  • Lineage: nstep_sarsa → tree_backup
  • Concept: Off-policy control without importance sampling, blending n-step returns with target-policy expectations.
  • Idea added: off-policy without importance sampling — target-policy expectations.
$$
G_{t:t+n} = \sum_{k=1}^{n} \gamma^{k-1} \Big(\prod_{i=1}^{k-1} \pi(A_{t+i}|S_{t+i})\Big) R_{t+k}
+ \gamma^n \Big(\prod_{i=1}^{n-1} \pi(A_{t+i}|S_{t+i})\Big) \sum_{a'} \pi(a'|S_{t+n}) Q(S_{t+n}, a')
$$

nstep_off_policy

  • Lineage: nstep_sarsa → nstep_off_policy
  • Concept: n-step control with per-decision importance ratios correcting the behavior policy.
  • Idea added: per-decision importance ratios.
$$
Q \leftarrow Q + \alpha\, \rho_{t+1:t+n}\big(G_t^{(n)} - Q(s,a)\big), \qquad
\rho_{t+1:t+n} = \prod_{k=1}^{n} \frac{\pi(A_{t+k}|S_{t+k})}{b(A_{t+k}|S_{t+k})}
$$

double_qlearning

  • Lineage: qlearning → double_qlearning
  • Concept: Two value tables, so the max of one can't inflate the other.
  • Idea added: twin tables remove maximization bias.
$$
Q_1(s,a) \leftarrow Q_1(s,a) + \alpha\Big(r + \gamma Q_2\big(s', \arg\max_{a'} Q_1(s',a')\big) - Q_1(s,a)\Big)
$$

td_lambda_prediction

  • Lineage: td0_prediction → td_lambda_prediction
  • Concept: Blend all n-step returns into one λ-weighted return — the MC↔TD dial.
  • Idea added: λ-weighted returns — the MC ↔ TD bridge.
$$
G_t^{\lambda} = (1-\lambda) \sum_{n=1}^{\infty} \lambda^{n-1} G_t^{(n)}
$$

sarsa_lambda

  • Lineage: sarsa → sarsa_lambda
  • Concept: Spread one step's TD error backward through eligibility traces, on-policy.
  • Idea added: eligibility traces for on-policy control.
$$
Q \leftarrow Q + \alpha \delta_t e_t, \qquad
\delta_t = r + \gamma Q(s',a') - Q(s,a), \qquad
e_t \leftarrow \gamma\lambda e_{t-1} + \mathbb{1}\{S_t = s,\, A_t = a\}
$$

q_lambda

  • Lineage: qlearning → q_lambda
  • Concept: Off-policy traces cut wherever the behavior action was not greedy.
  • Idea added: traces for off-policy control, cut at non-greedy actions.
$$
e_t \leftarrow \begin{cases} \gamma\lambda e_{t-1} + 1 & A_t \text{ greedy w.r.t. } Q \\ 0 & \text{otherwise} \end{cases}
$$

dyna_q

  • Lineage: qlearning → dyna_q
  • Concept: Learn a model on the side and plan by replaying simulated Q-learning backups.
  • Idea added: learn a model, then plan with simulated backups between real steps.
$$
\text{model: } (S_t, A_t) \to (R_{t+1}, S_{t+1}); \qquad \text{repeat } n \text{ times per step: Q-learning on sampled model transitions}
$$

dyna_q_plus

  • Lineage: dyna_q → dyna_q_plus
  • Concept: Plan with a small optimism bonus for pairs the real world stopped visiting.
  • Idea added: optimism bonus for stale pairs — optimism from UCB.
$$
r + \kappa\sqrt{\tau} \ \text{where } \tau \text{ = steps since } (s,a) \text{ last visited}
$$

prioritized_sweeping

  • Lineage: dyna_q → prioritized_sweeping
  • Concept: Plan only where the TD error is big — a priority queue of surprise.
  • Idea added: order planning by TD-error magnitude — ancestor of prioritized replay.
$$
p = \big|r + \gamma \max_{a'} Q(s',a') - Q(s,a)\big|
$$

Generation 3 — Function Approximation (and its dangers)

semi_gradient_sarsa

  • Lineage: sarsa → semi_gradient_sarsa
  • Concept: SARSA with the value table replaced by a function approximator.
  • Idea added: replace the table with a function approximator; semi-gradient update.
$$
w \leftarrow w + \alpha\big(r + \gamma \hat{Q}(s',a',w) - \hat{Q}(s,a,w)\big)\nabla_w \hat{Q}(s,a,w)
$$

naive_qlearning

  • Lineage: qlearning → naive_qlearning
  • Concept: Q-learning with a neural net and no stabilizers — the textbook way to diverge.
  • Idea added: neural Q + max bootstrap, no stabilizers — the deadly-triad anti-pattern.
$$
w \leftarrow w + \alpha\big(r + \gamma \max_{a'} \hat{Q}(s',a',w) - \hat{Q}(s,a,w)\big)\nabla_w \hat{Q}(s,a,w) \quad \text{(diverges)}
$$

gtd

  • Lineage: td0_prediction → gtd
  • Concept: Off-policy TD as true gradient descent, so it converges where naive TD diverges.
  • Idea added: true gradient off-policy TD with a second weight vector (GTD2).
$$
\delta_t = r_t + \gamma w_t^{\top}\phi_{t+1} - w_t^{\top}\phi_t, \qquad
w_{t+1} = w_t + \alpha_t \rho_t\big(\delta_t \phi_t - \gamma \phi_{t+1}(h_t^{\top}\phi_t)\big), \qquad
h_{t+1} = h_t + \beta_t \rho_t\big(\delta_t \phi_t - (h_t^{\top}\phi_t)\phi_t\big)
$$

tde

  • Lineage: td0_prediction → tde
  • Concept: TD(λ) made exact per step with the dutch eligibility trace.
  • Idea added: True Online TD(λ) — the dutch trace makes the per-step update exact.
$$
\delta_t = r_t + \gamma w_t^{\top}\phi_{t+1} - w_t^{\top}\phi_t, \qquad
e_t = \gamma\lambda e_{t-1} + \phi_t - \alpha\gamma\lambda (e_{t-1}^{\top}\phi_t)\phi_t, \qquad
w_{t+1} = w_t + \alpha \delta_t e_t
$$

emphatic_td

  • Lineage: td0_prediction → emphatic_td
  • Concept: Re-weight off-policy TD updates by emphasis so they match the target policy's visit distribution.
  • Idea added: re-weight the update by an emphasis that grows where the target policy visits more.
$$
M_t = \lambda \rho_{t-1} M_{t-1} + 1, \qquad
w_{t+1} = w_t + \alpha M_t \rho_t \delta_t \phi_t
$$

Generation 4a — Deep Q-Learning

dqn

  • Lineage: naive_qlearning → dqn
  • Concept: Deep Q-learning stabilized by experience replay and a target network.
  • Idea added: experience replay + target network — the fix for the deadly triad.
$$
\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s') \sim D}\Big[\big(r + \gamma \max_{a'} Q(s',a';\theta^{-}) - Q(s,a;\theta)\big)^2\Big]
$$

double_dqn

  • Lineage: dqn → double_dqn
  • Concept: DQN that selects with the online net and evaluates with the target — an unbiased max.
  • Idea added: select with the online net, evaluate with the target net.
$$
y = r + \gamma Q\big(s', \arg\max_{a'} Q(s',a';\theta); \theta^{-}\big)
$$

dueling_dqn

  • Lineage: dqn → dueling_dqn
  • Concept: Split Q into value plus advantage streams so the network learns state value directly.
  • Idea added: split the head into V and advantage streams.
$$
Q(s,a) = V(s) + A(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'} A(s,a')
$$

prioritized_dqn

  • Lineage: dqn → prioritized_dqn
  • Concept: Replay that samples the transitions with the biggest TD errors.
  • Idea added: sample replay by TD-error magnitude.
$$
p_i \propto |\delta_i|^{\alpha}, \qquad w_i = (N \cdot p_i)^{-\beta}
$$

c51

  • Lineage: dqn → c51
  • Concept: Predict the whole distribution of returns, not just the mean.
  • Idea added: predict the distribution over returns (51 atoms).
$$
\mathcal{L} = \mathrm{KL}\big(\Phi(\mathcal{T} d)\;\|\; d(s,a)\big), \qquad
z_j = V_{\min} + j\,\Delta \ (j = 0, \dots, 50)
$$

qr_dqn

  • Lineage: c51 → qr_dqn
  • Concept: The distributional idea with quantiles instead of a fixed atom grid.
  • Idea added: quantile regression instead of a fixed atom grid.
$$
\mathcal{L} = \sum_{i,j} \rho_{\tau_i}\big(z_j^{\text{target}} - Z_\theta(s,a)_i\big), \qquad
\rho_\tau(u) = u\big(\tau - \mathbb{1}\{u < 0\}\big)
$$

rainbow

  • Lineage: double_dqn + dueling_dqn + prioritized_dqn + c51 + n-step + noisy → rainbow
  • Concept: The sum of every DQN improvement, in one agent.
  • Idea added: every DQN improvement in one agent.
$$
\mathcal{L} = \text{double Q target} + \text{dueling architecture} + \text{prioritized sampling} + \text{categorical distribution} + \text{n-step returns} + \text{noisy nets}
$$

Generation 4b — The Policy-Gradient Lineage's First Children

reinforce_baseline

  • Lineage: reinforce → reinforce_baseline
  • Concept: REINFORCE with a value baseline that removes variance, not bias.
  • Idea added: subtract a learned baseline — variance reduction without bias.
$$
\nabla_\theta J = \mathbb{E}\big[\nabla_\theta \log \pi_\theta(a|s)\big(G_t - b(s)\big)\big]
$$

actor_critic

  • Lineage: reinforce_baseline → actor_critic
  • Concept: An actor that moves the policy and a critic that grades each step.
  • Idea added: bootstrapped critic instead of the full return.
$$
\delta = r + \gamma V(s') - V(s), \qquad
\theta \leftarrow \theta + \alpha \nabla_\theta \log \pi_\theta(a|s)\, \delta, \qquad
w \leftarrow w + \beta\, \delta\, \nabla_w V(s)
$$

a2c

  • Lineage: actor_critic → a2c
  • Concept: Many parallel actors reporting to one critic for lower-variance updates.
  • Idea added: synchronous parallel actors + n-step advantages.
$$
A_t = \sum_{k=1}^{n} \gamma^{k-1} R_{t+k} + \gamma^n V(S_{t+n}) - V(S_t)
$$

trpo

  • Lineage: a2c → trpo
  • Concept: Update the policy only inside a KL trust region where the change is provably safe.
  • Idea added: constrain updates to a KL trust region.
$$
\max_\theta \mathbb{E}\Big[\frac{\pi_\theta(a|s)}{\pi_{\text{old}}(a|s)} A\Big] \quad \text{s.t.} \quad D_{\mathrm{KL}}\big(\pi_{\text{old}}\,\|\,\pi_\theta\big) \le \delta
$$

ppo

  • Lineage: trpo → ppo
  • Concept: The same safety via a clipped surrogate objective — cheap and stable.
  • Idea added: clipped surrogate — same stability, much cheaper.
$$
\mathcal{L} = \mathbb{E}\Big[\min\big(r_t(\theta) A_t,\ \mathrm{clip}\big(r_t(\theta), 1\pm\varepsilon\big) A_t\big)\Big], \qquad
r_t(\theta) = \frac{\pi_\theta(a_t|s_t)}{\pi_{\text{old}}(a_t|s_t)}
$$

Generation 5 — Continuous Control

ddpg

  • Lineage: dqn + actor_critic → ddpg
  • Concept: An actor that learns by backprop through a critic's Q, for continuous actions.
  • Idea added: deterministic policy gradient — train an actor by backprop through the critic.
$$
\nabla_\theta J = \mathbb{E}_D\big[\nabla_a Q(s,a;\phi)\big|_{a=\mu_\theta(s)} \nabla_\theta \mu_\theta(s)\big], \qquad
y = r + \gamma Q'\big(s', \mu'(s')\big)
$$

td3

  • Lineage: ddpg → td3
  • Concept: DDPG with twin critics, delayed updates, and smoothed targets to stop overestimation.
  • Idea added: twin critics (min), delayed updates, target-policy smoothing.
$$
y = r + \gamma \min_{i=1,2} Q_i'\big(s', \mu'(s') + \mathrm{clip}(\epsilon, -c, c)\big), \qquad
\epsilon \sim \mathcal{N}(0, \sigma)
$$

sac

  • Lineage: td3 → sac
  • Concept: Maximize reward and entropy at once, with an auto-tuned temperature.
  • Idea added: maximum entropy — exploration as a first-class objective, auto-tuned temperature.
$$
J(\pi) = \sum_t \mathbb{E}\big[R_t + \alpha \mathcal{H}\big(\pi(\cdot|s_t)\big)\big], \qquad
\alpha \text{ tuned to a target entropy}
$$

Generation 6 — Off-Policy & Distributed Actor-Critics

impala

  • Lineage: a2c → impala
  • Concept: A central learner correcting many actors' stale trajectories with V-trace.
  • Idea added: V-trace — per-step importance correction for learning from parallel actors.
$$
\rho_t = \min\Big(\bar\rho, \frac{\pi(a_t|s_t)}{\mu(a_t|s_t)}\Big), \quad
c_i = \min\Big(\bar c, \frac{\pi(a_i|s_i)}{\mu(a_i|s_i)}\Big), \qquad
v_s = V(s) + \sum_{t \ge s} \gamma^{t-s} \Big(\prod_{i=s}^{t-1} c_i\Big) \rho_t \big(r_t + \gamma V(s_{t+1}) - V(s_t)\big)
$$

acer

  • Lineage: impala → acer
  • Concept: Off-policy actor-critic with truncated importance ratios and a trust-region gradient.
  • Idea added: truncated IS actor update + retrace critic target + trust-region gradient.
$$
g = \rho_t \nabla_\theta \log \pi_\theta(a_t|s_t)\, A_t + \underbrace{\mathbb{E}_{a \sim \mu}\big[\rho(a) \hat{Q}_{\text{retrace}}(s,a) \nabla_\theta \log\pi_\theta\big] - \mathbb{E}_{a \sim \pi}\big[\rho(a) \hat{Q}(s,a) \nabla_\theta \log\pi_\theta\big]}_{\text{bias correction}}
$$

acktr

  • Lineage: impala → acktr
  • Concept: A2C with a Kronecker-factored natural gradient instead of Adam.
  • Idea added: Kronecker-factored natural gradient — trust region at Adam's cost.
$$
F \approx G \otimes A \quad \text{(Kronecker product of input and gradient covariances)}, \qquad
\Delta\theta = -F^{-1}\nabla_\theta \mathcal{L}
$$

Generation 7 — Model-Based & Learned World Models

mcts

  • Lineage: dyna_q → mcts
  • Concept: Plan by building a search tree, balancing exploration with UCB1.
  • Idea added: tree search over the true model — UCB1 selection, rollout evaluation.
$$
a = \arg\max_a\Big[Q(s,a) + c\sqrt{\frac{\ln N(s)}{N(s,a)}}\Big], \qquad
Q(s,a) = \frac{\text{returns through } (s,a)}{N(s,a)}
$$

alphazero

  • Lineage: mcts → alphazero
  • Concept: MCTS whose rollouts are replaced by a learned policy-value network trained by self-play.
  • Idea added: PUCT search guided by learned policy/value networks; self-play data.
$$
a = \arg\max_a\Big[Q(s,a) + c_{\text{puct}} P(s,a)\frac{\sqrt{N(s)}}{1+N(s,a)}\Big], \qquad
\mathcal{L} = (z - v)^2 - \pi^{\top}\log p + c\|\theta\|^2
$$

muzero

  • Lineage: alphazero → muzero
  • Concept: The same planning, but the model itself is learned in a latent space.
  • Idea added: learn the model in latent space — representation, dynamics, prediction.
$$
h = f_\theta(s), \quad (h', r, d) = g_\theta(h, a), \quad (p, v) = l_\theta(h), \qquad
\mathcal{L} = \mathcal{L}_{\text{value}} + \mathcal{L}_{\text{reward}} + \mathcal{L}_{\text{policy}} + \big\|h_2 - f_\theta(s')\big\|^2
$$

world_models

  • Lineage: mcts → world_models
  • Concept: Compress the world (VAE), predict it (MDN-RNN), evolve a controller inside dreams (CEM).
  • Idea added: generative latent model (VAE + MDN-RNN) and evolutionary control (CEM) in dreams.
$$
\mathcal{L}_{\text{VAE}} = \mathbb{E}_{q(z|x)}\big[-\log p(x|z)\big] + \mathrm{KL}\big(q(z|x)\,\|\,p(z)\big), \qquad
p(z_{t+1}|z_t, h_t) = \sum_k \pi_k \mathcal{N}(\mu_k, \sigma_k)
$$

dreamer

  • Lineage: world_models → dreamer
  • Concept: Learn an RSSM of the world, then train an actor-critic purely in imagination.
  • Idea added: RSSM world model + actor-critic trained purely in imagination.
$$
h_t = \mathrm{GRU}(h_{t-1}, z_{t-1}, a_{t-1}), \quad z_t \sim q(z_t|h_t, x_t), \qquad
\mathcal{L} = \underbrace{\text{reconstruction} + \text{reward} + \text{continuation} + \text{free-bits KL}}_{\text{world model}}
$$

$$
\text{actor: } \nabla_\theta J \approx \mathbb{E}\big[\nabla_\theta \log \pi_\theta(a|z)\big(V_\lambda - V\big)\big] + \beta\, \mathcal{H}\big(\pi(\cdot|z)\big)
$$

Generation 8 — Multi-Agent & Goal-Conditioned RL

maddpg

  • Lineage: ddpg → maddpg
  • Concept: Independent actors, centralized critics that see everyone's observations and actions.
  • Idea added: per-agent actors + centralized critics over the joint observation/action (CTDE).
$$
y_i = r + \gamma Q_i'\big(o', \mu_1'(o_1'), \dots, \mu_n'(o_n')\big), \qquad
\nabla_{\theta_i} J_i = \mathbb{E}\big[\nabla_{\theta_i} \mu_i(o_i)\, \nabla_{a_i} Q_i(o, a)\big]
$$

mappo

  • Lineage: ppo → mappo
  • Concept: Independent PPO policies sharing one joint-state critic's advantage.
  • Idea added: independent PPO policies sharing one centralized critic's advantage.
$$
\mathcal{L}_i = \mathbb{E}\Big[\min\big(r_i A,\ \mathrm{clip}(r_i, 1\pm\varepsilon) A\big)\Big], \qquad
A \text{ from the joint-state critic via GAE}
$$

qmix

  • Lineage: dqn → qmix
  • Concept: Per-agent Qs mixed into a joint Q that each agent's argmax can execute.
  • Idea added: decompose the joint Q into per-agent Qs mixed by a nonnegative hypernetwork (IGM).
$$
Q_{\text{tot}}(\tau, u) = f_{\text{mix}}\big(s, Q_1, \dots, Q_n\big), \quad
\frac{\partial Q_{\text{tot}}}{\partial Q_i} \ge 0, \qquad
\arg\max_u Q_{\text{tot}} = \big(\arg\max_{u_1} Q_1, \dots, \arg\max_{u_n} Q_n\big)
$$

her

  • Lineage: ddpg → her
  • Concept: Replay failed episodes with the goal replaced by where you actually ended up.
  • Idea added: hindsight relabeling — replay failed episodes under goals actually achieved.
$$
g \leftarrow s_{t_f} \ \text{(a future state)}, \qquad
r' = \mathbb{1}\big\{\|s_{t+1} - g'\| < \varepsilon\big\}
$$

DQN-Family Extras

icm

  • Lineage: dqn → icm
  • Concept: Reward curiosity: the error of predicting your own next state.
  • Idea added: intrinsic reward from forward-model prediction error, features pinned by an inverse model.
$$
r^i = \big\|\phi(s_{t+1}) - \hat\phi(s_{t+1})\big\|^2, \qquad
\mathcal{L}_{\text{inv}} = \mathrm{CE}\big(\hat a_t, a_t\big)
$$

rnd

  • Lineage: dqn → rnd
  • Concept: Reward novelty: how far a predictor is from a frozen random target.
  • Idea added: intrinsic reward from distilling a frozen random network — novelty without an inverse model.
$$
r^i = \big\|f(s') - \hat f(s')\big\|^2, \qquad f \text{ fixed random network}
$$

r2d2

  • Lineage: rainbow → r2d2
  • Concept: Recurrent Q-learning over replayed sequences with burn-in and value rescaling.
  • Idea added: recurrent LSTM Q with burn-in, prioritized sequence replay, value rescaling.
$$
h(x) = \mathrm{sign}(x)\big(\sqrt{|x| + 1} - 1\big) + \varepsilon x
$$

agent57

  • Lineage: r2d2 → agent57
  • Concept: A bandit over (γ, β) decides which exploration/credit dials each training run uses.
  • Idea added: a UCB bandit over (γ, β) parameterizations — meta-control of credit and exploration.
$$
\text{arm } k: \ \text{score}_k = \mu_k + c\sqrt{\frac{\ln t}{N_k}}, \qquad
r^{\text{total}} = r^{\text{extrinsic}} + \beta \cdot r^{\text{intrinsic}}
$$

cql

  • Lineage: dqn → cql
  • Concept: Offline Q-learning that pushes Q down on actions the data never chose.
  • Idea added: offline — penalize Q on out-of-distribution actions.
$$
\mathcal{L} = \alpha\Big(\mathbb{E}_{s \sim D,\, a \sim \mu}\big[\log \textstyle\sum_{a'} e^{Q(s,a')}\big] - \mathbb{E}_{D}\big[Q(s,a)\big]\Big) + \mathcal{L}_{\text{TD}}
$$

iql

  • Lineage: dqn → iql
  • Concept: Learn only from in-data actions: expectile value, then imitate the good ones.
  • Idea added: offline — expectile regression of V, advantage-weighted behavioral cloning of π.
$$
V = \arg\min_V \mathbb{E}\big[L_2^{\tau}\big(Q - V\big)\big], \qquad
\pi = \arg\max_\pi \mathbb{E}\big[\log \pi(a|s)\, \exp\big(\beta (Q - V)\big)\big]
$$

decision_transformer

  • Lineage: off-tree
  • Concept: Frame RL as next-token prediction over return-to-go, state, and action sequences.
  • Idea added: RL as sequence modeling — a causal transformer over (return-to-go, state, action) tokens.
$$
a_t \sim \mathrm{GPT}_\theta\big(\hat R_{t-n:t},\ s_{t-n:t},\ a_{t-n-1:t-1}\big), \qquad
\mathcal{L} = \mathrm{CE}\big(a_t, \hat a_t\big)
$$
