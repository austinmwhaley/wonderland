Reinforcement Learning Algorithm Family Tree

This document maps every algorithm in the registry onto a family tree: each algorithm is a node, and an edge A → B means B inherits A's machinery and adds one idea — the edge itself is labeled with that delta. Reading from the roots down, each generation is a story of what was added to the previous one.

Notation used below:

node             an algorithm (registry name)
A → B  [+delta]  B descends from A; the edge is the delta (difference/addition)

All 66 implemented algorithms are custom PyTorch (no external RL libraries). The registry is complete: every planned stub has been implemented.

The Five Roots (Generation 0)

Everything in the tree grows from five independent ideas. Three of them (DP, MC, TD) rest on the same mathematical object — the expected return — but estimate it from different sources (a model, complete episodes, partial episodes); bandits isolate exploration from state; and the policy gradient skips value estimation entirely and optimizes the policy itself.

0.1 — Bandits: the simplest decision problem

epsilon_greedy_bandit

Learn action values from rewards; explore by random ε. No state, no dynamics — this isolates the exploration/exploitation problem, which every later generation inherits in some form.

0.2 — Dynamic Programming: value from a model

policy_evaluation

Repeatedly apply the Bellman backup over the environment's explicit transition table. This is the planning root: it shows that a value function exists and can be computed exactly when you know .P. It also introduces the backup operation — the single most reused idea in the tree.

0.3 — Monte Carlo: value from complete episodes

mc_prediction

Drop the model; average full-episode returns for the states actually visited. This is the model-free episodic root: unbiased, high-variance, and it introduces the notion of the return.

0.4 — Temporal Difference: value from the next estimate

td0_prediction

Combine 0.2 and 0.3: bootstrap the value from the next state's estimate (DP's idea) using sampled transitions (MC's idea). No model, low variance, biased. Every learning algorithm below descends from this lineage, from the MC lineage, or from the policy-gradient root (0.5).

0.5 — Policy Gradient: optimize the policy directly

reinforce

The fifth root, and the only one that never estimates a value function: parameterize the policy and ascend the gradient of expected return, \(\mathbb{E}[\nabla \log \pi(\theta) \cdot Q]\). Its primitive object is the policy distribution rather than the value function, and it needs no Bellman backup at all. Two of its structural ideas appear in miniature inside the bandit root — gradient_bandit's softmax preferences and baseline are literally a single-state policy gradient — and the return it maximizes is the same object MC averages, but the derivation stands alone: it is a theorem about the gradient of a distribution, not an estimator of a value.

Generation 1 — First Children

The roots produce control algorithms: things that act.

Edge Delta (what the child adds)
policy_evaluation → policy_iteration Greedy policy improvement step after each evaluation pass
policy_iteration → value_iteration Fuse evaluation + improvement into one in-place Bellman optimality backup
mc_prediction → mc_control_onpolicy Learn Q (state-action values) under an ε-soft policy; improve between episodes
mc_prediction → mc_control_offpolicy Target the greedy policy by reweighting returns with importance sampling
td0_prediction → sarsa On-policy control: bootstrap with the next action actually taken
td0_prediction → qlearning Off-policy control: bootstrap with the max next action — learns the optimal Q directly
epsilon_greedy_bandit → optimistic_bandit Replace ε with optimistic initialization — explore by being wrong
epsilon_greedy_bandit → ucb_bandit Replace ε with an uncertainty bonus \(c \cdot \sqrt{\ln t / N}\)
epsilon_greedy_bandit → gradient_bandit Replace action values with softmax preferences learned by gradient ascent + a baseline
epsilon_greedy_bandit → thompson_sampling Sample actions from a Bayesian posterior over arm means

gradient_bandit is historically important: preference learning with a baseline is the policy-gradient idea in miniature (see root 0.5). ucb_bandit's optimism is the ancestor of every exploration bonus below.

What this generation added: the control loop — policies that improve from their own experience — and the two flavors of TD control (on-policy sarsa, off-policy qlearning) that structure everything that follows.

Generation 2 — Refinements of TD Control

Two motivations drive this generation: lower variance and faster credit assignment. Almost every child here is a delta on the bootstrap target.

2.1 Bias / variance dials

Edge Delta
sarsa → expected_sarsa Bootstrap with the expected next value instead of the sampled one — variance reduction
sarsa → nstep_sarsa Wait n steps before bootstrapping — dial from TD (n=1) toward MC (n=∞)
nstep_sarsa → nstep_expected_sarsa Combine n-step returns with expected-value bootstrapping
nstep_sarsa → tree_backup Make it off-policy without importance sampling: bootstrap with target-policy expectations
nstep_sarsa → nstep_off_policy Make it off-policy with per-decision importance ratios
qlearning → double_qlearning Two Q tables: selection and evaluation use different tables — removes maximization bias

double_qlearning's twin-table trick is reused a generation later in double_dqn; expected_sarsa's expectation trick is reused in tree_backup and in deep Q targets.

2.2 Eligibility traces (the MC ↔ TD bridge)

Edge Delta
td0_prediction → td_lambda_prediction λ-weighted returns — one step of work, credit spread over many steps
sarsa → sarsa_lambda Traces for on-policy control
qlearning → q_lambda Traces for off-policy control; traces cut wherever the behavior action is non-greedy

The trace idea (and its λ dial) reappears two generations later as GAE in PPO.

2.3 Model-based planning (a separate branch off Q-learning)

Edge Delta
qlearning → dyna_q Learn a model of transitions, then run simulated Q-learning backups between real steps
dyna_q → dyna_q_plus Add an exploration bonus κ·√τ to stale (s,a) pairs — optimism from ucb_bandit
dyna_q → prioritized_sweeping Order planning by TD-error magnitude via a priority queue — the ancestor of prioritized replay

What this generation added: principled ways to spend the bootstrap dial (MC↔TD), variance reduction, bias correction, and the notion that planning should focus on the transitions that matter most.

Generation 3 — Function Approximation (the bridge to deep)

The tabular era ends when the state space becomes continuous. The value table becomes a function approximator — and the deadly triad is discovered.

Edge Delta
sarsa → semi_gradient_sarsa Replace the table with a neural Q (tile-coded here); updates are semi-gradients of the TD error
qlearning → naive_qlearning The same move, but off-policy: neural Q + max bootstrap, no replay, no target net

naive_qlearning is included deliberately as the anti-pattern: off-policy bootstrapping + function approximation + stochastic sampling is exactly the recipe that diverges. DQN exists to fix this node.

What this generation added: the insight that function approximation changes the game — the reason every deep method below adds stabilizers.

Generation 4a — Deep Q-Learning (the DQN family)

Edge Delta
naive_qlearning → dqn The fix for the deadly triad: experience replay (decorrelates samples) + target network (fixed-Q targets, delayed evaluation) + gradient-based Q update
dqn → double_dqn Reuse double_qlearning's twin-table trick: select with the online net, evaluate with the target net
dqn → dueling_dqn Split the output head into V(s) + A(s,a) streams — learn action-independent value directly
dqn → prioritized_dqn Reuse prioritized_sweeping's idea: sample replay by TD-error magnitude (sum-tree), with importance corrections
dqn → c51 Distributional: predict the distribution over returns (51 atoms) instead of a point estimate
c51 → qr_dqn Replace categorical atoms with quantile regression (Huber loss) — more flexible return geometry
double_dqn + dueling_dqn + prioritized_dqn + c51 + n-step + noisy nets → rainbow The synthesis: every DQN improvement in one agent

What this generation added: the stabilizers (replay, targets), the distributional insight, and the demonstration that each improvement is additive. rainbow is the state of the art of this lineage.

Generation 4b — The Policy-Gradient Lineage's First Children

The policy-gradient root (0.5) branches here: its first algorithms make the idea practical. REINFORCE realizes the root with full-episode returns; each child fixes one of its weaknesses — variance (baseline), bias (bootstrapped critic), throughput (parallel actors), stability (trust regions).

Edge Delta
(root) → reinforce Policy gradient theorem: \(\nabla J = \mathbb{E}[\nabla \log \pi \cdot G]\); uses full-episode MC returns
reinforce → reinforce_baseline Subtract a learned value baseline from G — variance reduction without bias
reinforce_baseline → actor_critic Replace the full return with a bootstrapped critic estimate — TD-style bias for much lower variance
actor_critic → a2c Synchronous parallel actors (N envs) + n-step advantage estimates — the sync version of A3C
a2c → trpo Constrain each update to a KL trust region around the old policy — monotone improvement guarantee
trpo → ppo Replace the hard KL constraint with a clipped surrogate objective — same stability, 10× cheaper
td_lambda_prediction → ppo (cross-lineage) GAE(λ): the trace idea as a per-step advantage estimator

What this generation added: the policy-gradient theorem (root), the baseline (variance), bootstrapping (bias-for-variance trade), parallelism (throughput), and trust regions → clipping (stability). PPO is the terminal node of this branch.

Generation 5 — Continuous Control (the fusion)

DDPG is the marriage of two lineages: the replay/target architecture of the DQN family and the actor-critic machinery of the PG family, applied to continuous actions via the deterministic policy gradient.

Edge Delta
dqn + actor_critic → ddpg Deterministic policy gradient: train an actor by backprop through the critic; replay + target nets from DQN
ddpg → td3 Three targeted fixes: twin critics (min over two Qs — double_qlearning's trick again), delayed policy updates, target-policy smoothing
td3 → sac Replace the deterministic actor with a maximum-entropy stochastic policy: soft Q-targets + automatic temperature — robust exploration as a first-class objective

What this generation added: bridging value and policy methods, correcting DDPG's overestimation, and (in SAC) turning exploration into part of the objective itself. SAC is the terminal node of the continuous branch.

Generation 6 — Off-Policy & Distributed Actor-Critics

The PG lineage matures in two directions: make actor-critics off-policy (learn from stale data) and make them scale (many parallel actors).

Edge Delta
a2c → impala Parallel actors + a centralized learner with V-trace — a per-step importance-corrected target that stays unbiased off-policy without full IS
impala → acer Add an off-policy truncated IS actor update + a trust-region gradient (the trpo idea at low cost) + a retrace critic target
impala → acktr Replace the Adam step with a Kronecker-factored natural gradient (KFAC) — trpo's trust region via approximate Fisher preconditioning

What this generation added: the machinery to train a single model from many actors' trajectories (the architectural ancestor of modern distributed RL) and trust-region ideas cheap enough to run every step.

Generation 7 — Model-Based & Learned World Models

A separate lineage off the DP/dyna root: instead of planning over the true model, learn the model and plan (or imagine) inside it.

Edge Delta
dyna_q → mcts Tree search over the true transition function: evaluate leaves with rollouts, select with UCB1 — planning without learning
mcts → alphazero Replace the rollout evaluation with a learned policy/value network and guide selection with PUCT — learn to plan (self-play over a model)
alphazero → muzero Learn the model in latent space (representation + dynamics + prediction heads) so no dynamics model of the real env is needed
mcts → world_models Replace tree search with a generative latent model (VAE + MDN-RNN) and evolve a controller (CEM) inside dreams
world_models → dreamer Replace the evolutionary controller with an actor-critic trained in imagination on an RSSM world model (free-bits KL, obs/rew/cont heads)

What this generation added: the insight that the model itself can be learned end-to-end and that planning can happen in a compressed latent space — from tabular Dyna-Q planning to MuZero and Dreamer.

Generation 8 — Multi-Agent & Goal-Conditioned RL

The last branch extends the value/PG lineages to multiple interacting agents and to sparse-reward goal tasks.

Edge Delta
ppo → mappo Independent PPO policies per agent + one centralized critic over the joint state (CTDE)
ddpg → maddpg Independent actors + centralized critics that see all agents' observations and actions (CTDE); double-Q joint targets in this discrete port
dqn / qmix Decompose the joint Q into per-agent Qs mixed by a nonnegative state-dependent hypernetwork (IGM) — preserves decentralized argmax execution
ddpg → her Goal-conditioned value learning with hindsight relabeling: failed episodes are replayed under goals the agent actually reached

What this generation added: centralized training with decentralized execution, value decomposition for cooperative tasks, and turning sparse rewards dense by relabeling. On the cooperative benchmark, qmix (91-93) finds the anti-correlated equilibrium that the independent-policy CTDE methods (maddpg, mappo) cannot.

Off-Policy Extras (the DQN family's late children)

Edge Delta
rainbow → r2d2 Recurrent LSTM Q with burn-in, prioritized replay of full sequences, n-step returns, value rescaling
r2d2 → agent57 A UCB bandit over (γ, β) parameterizations — meta-control of the exploration/credit dials
dqn → icm Intrinsic reward from a forward model whose features are pinned by an inverse model
dqn → rnd Intrinsic reward from random network distillation — simpler, no inverse model
dqn → cql Offline: penalize Q on out-of-distribution actions (log-sum-exp minus data-action Q)
dqn → iql Offline: expectile regression of the value + advantage-weighted behavioral cloning
(off-tree) → decision_transformer Causal transformer over (return-to-go, state, action) — RL as sequence modeling on fixed data

The Dense-Reward Bootstrap Problem (a lesson the model-based agents hit)

On dense-reward tasks (cartpole's +1 per step), a pure value-net or latent-model leaf evaluation is degenerate: under the near-uniform policies of early search, every action has nearly the same value, so the tree gets no gradient. The implementations solve it three ways, all documented in the registry:

  • AlphaZero blends network leaves with short real-model rollouts (0.5·net_v + 0.5·rollout_ret).
  • MuZero adds a continuation head (else the latent model can never encode survival, since rewards are constant) plus a one-ply real lookahead to break the random-policy bootstrap.
  • Dreamer must see the terminal transition (stored next_obs) and a class-weighted continuation loss, or dreams never end and the actor gets no signal.

The same disease appears in multi-agent form: on cooperative_cartpole the optimal strategy is anti-correlated (opposing forces), and the batch-averaged policy gradients of MADDPG/MAPPO average away the per-state advantages and collapse to correlated play (ret ~8-12), while QMIX's per-sample Q-fitting preserves the state-conditional ordering and finds it (ret ~91-93).

All algorithms in this document are implemented from scratch in PyTorch (see algorithms/). External RL libraries are not used; stable-baselines3 was briefly installed only as a diagnostic comparison for one benchmark run and has been removed from the environment.

Glossary

Every key term used in this document, in one place.

Term Meaning
Action-value function Q(s, a) The expected return from taking action a in state s, then following the policy.
Actor-critic Architecture pairing a policy ("actor") with a value estimate ("critic") used as its baseline.
Advantage A(s, a) Q(s, a) − V(s): how much better an action is than the policy's average. The natural signal for policy gradients.
Atoms The discrete support points of a categorical return distribution (C51 uses 51).
Attention The transformer mechanism that lets each token look at every other token when predicting.
AWR (advantage-weighted regression) Behavioral cloning reweighted by advantage — the policy-fitting step in IQL.
Baseline A value subtracted from the return in a policy update to cut variance without bias.
Bellman backup The operation of updating a value estimate using its successor states' estimates.
Bellman equation V(s) = E[r + γV(s′)]: the fixed-point equation every value function satisfies.
Behavior policy The policy that actually generates data (may differ from the target policy being learned).
Bootstrapping Updating a value estimate with another estimate (e.g. TD) rather than a complete return.
Burn-in Feeding recurrent networks a warm-up prefix so the hidden state reflects the past before learning.
Causal transformer A transformer that only attends to the past (no future leakage) — required for sequence prediction.
CEM (cross-entropy method) A derivative-free optimizer: sample, keep the elite, refit the sampling distribution.
Clipped surrogate objective PPO's loss: cap the importance ratio at 1±ε so updates never overshoot.
Control problem The problem of finding the best policy — the thing every control algorithm in this tree solves. Contrast with the prediction problem; control typically alternates evaluation with improvement (GPI).
CTDE Centralized Training, Decentralized Execution: agents learn with joint information but act on their own observations.
Deadly triad The three ingredients — off-policy learning, bootstrapping, function approximation — that together can make value learning diverge.
Deterministic policy gradient The gradient of the expected return w.r.t. the policy parameters when the policy is a deterministic function (DDPG).
Dirichlet noise Random noise added to the root's prior in MCTS to force exploration in self-play.
Discount factor γ How much future rewards count (γ<1 makes the return finite).
Distributional RL Predicting the full distribution of returns rather than only the mean.
Double estimator Using two independent value estimates so the max of one doesn't bias the other (kills maximization bias).
DP (dynamic programming) Computing values from a known model by repeated Bellman backups.
Dyna Interleaving real experience with planning backups through a learned model.
Eligibility traces A decaying memory of recently visited states/actions that spreads credit across many steps at once (λ).
ε-greedy Mostly greedy, but with probability ε take a random action.
Emphatic TD Off-policy TD re-weighted by an emphasis factor so the update distribution matches the target policy.
Episode A full interaction sequence from start to terminal state (or horizon cutoff).
Expectile regression Fitting a conditional value at a quantile-like level (τ) — IQL's way of avoiding OOD targets.
Expected SARSA SARSA with the expected next value under the policy instead of the sampled one.
Exploration / exploitation The tradeoff between trying new actions and using what already works.
Free-bits KL A lower bound on the KL loss so the latent prior is not forced to collapse early (Dreamer).
Function approximation Representing the value/policy with a parameterized function (e.g. a neural net) instead of a table.
GAE(λ) Generalized Advantage Estimation: λ-weighted advantages, the trace idea applied to advantage.
Generalized policy iteration (GPI) The alternating loop of policy evaluation and policy improvement — the abstract shape of nearly every control method in this tree (DP, MC, TD, and their descendants).
Goal-conditioned RL Learning policies parameterized by a goal, so one policy can reach many targets.
GRU A gated recurrent unit: a lightweight recurrent network cell.
GTD (gradient TD) Off-policy TD updates derived as true gradient descent, stable under the deadly triad.
Hindsight relabeling Replaying a failed episode with the goal replaced by one the agent actually achieved.
Horizon The length cap of an episode (truncation).
Hypernetwork A network that generates the weights of another network (QMIX's mixer weights).
IGM (individual-global-max) The property that the joint-optimal action is the per-agent argmaxes — what value decomposition must preserve.
Imagination Policy/value training inside a learned world model rather than the real environment.
Importance sampling (IS) Reweighting data collected under one policy to estimate expectations under another.
Intrinsic reward A self-generated bonus (novelty, prediction error) added to the extrinsic reward.
Inverse model A net predicting the action from two consecutive states — pins features to actionability (ICM).
KFAC Kronecker-factored approximate curvature: an affordable natural-gradient preconditioner (ACKTR).
KL divergence A distance between probability distributions; used as a trust-region constraint.
λ (lambda) The trace/dial parameter blending TD (λ=0) with MC (λ=1).
Latent consistency loss Penalizing ‖h2 − f(s′)‖ so the latent model's predictions agree with the true next representation (MuZero).
Latent model Planning in a compressed hidden representation instead of raw states.
Maximization bias The max of noisy estimates overestimates the true max — why double estimators exist.
Maximum-entropy RL Adding an entropy bonus to the objective so the policy stays exploratory (SAC).
Markov decision process (MDP) The formal model of sequential decision making: states, actions, transition/reward dynamics, discounting. Every environment in this tree is an MDP.
MC (Monte Carlo) Estimating values by averaging complete episode returns.
MCTS Monte Carlo Tree Search: iterative selection, expansion, simulation, backprop over a search tree.
MDN-RNN Mixture-density network on top of an RNN: predicts a Gaussian mixture over the next latent (World Models).
Model-based RL Learning/using a model of the environment's dynamics to plan or imagine.
Model of the environment The (learned or given) dynamics p(s′, r
n-step return Waiting n steps before bootstrapping — a dial between TD and MC.
Natural gradient Updating in a space where the geometry respects the information metric (KL), not the parameter coordinates.
Off-policy Learning a target policy from data generated by a different behavior policy.
Offline RL Learning from a fixed dataset with no further environment interaction.
On-policy Learning the policy that generates the data — behavior and target coincide.
Optimal policy / optimal value function The best policy π (and its value V, Q*) — the fixed point control algorithms converge toward; every control problem's answer.
Optimistic initialization Starting values high so exploration happens "by being wrong".
Policy A rule π(s) → action (or action distribution) mapping states to decisions.
Policy evaluation Computing a policy's value function — the prediction problem for a fixed policy.
Policy gradient theorem \(\nabla J = \mathbb{E}[\nabla \log \pi \cdot Q]\): the expected gradient of the return w.r.t. policy parameters.
Policy improvement Making the policy greedier (or better in some other provable way) w.r.t. its current value function — the second half of GPI.
Policy iteration Alternating full evaluation with greedy improvement until the policy stops changing.
Polyak averaging Soft target updates: θ_target ← (1−τ)·θ_target + τ·θ.
Prediction problem The problem of estimating a given policy's value function, without yet asking which policy is best — the simpler half of RL; control (GPI) builds on it.
PUCT The UCB variant AlphaZero uses: prior × exploration bonus balances learning with prior knowledge.
Quantile regression Regression onto specified return quantiles instead of a fixed atom grid (QR-DQN).
Replay (experience replay) Storing past transitions and sampling random batches — decorrelates data, stabilizes DQN.
Return The (discounted) sum of rewards from a point onward: G = r₁ + γr₂ + γ²r₃ + …
Retrace An off-policy correction that truncates IS ratios and can be applied to long traces.
Return-to-go The remaining return an offline trajectory still has to achieve — the conditioning token of the Decision Transformer.
RND (random network distillation) Intrinsic novelty = the error of predicting a frozen random network's output.
Rollout A short simulation from a search node to estimate its value.
RSSM Recurrent State-Space Model: deterministic recurrent state + stochastic latent (Dreamer).
Self-play Training against one's own current policy — the data source for AlphaZero.
Semi-gradient Updating only part of the loss's gradient (treating the target as fixed) — the standard TD-with-networks trick.
Softmax preferences Action scores turned into a softmax distribution, learned by gradient ascent (gradient bandits, policy gradients).
Sum-tree A binary tree enabling O(log n) weighted sampling by priority (prioritized replay).
Tabular Representing values in an explicit table, one entry per state (or state-action).
Target network A lagging copy of the value net used to compute stable TD targets.
Target-policy smoothing Adding noise to the next action in the TD target so the critic learns a robust max (TD3).
TD error r + γV(s′) − V(s): the surprise that drives every temporal-difference update.
Temperature The sharpness dial of a softmax (or the entropy scale in SAC).
Terminal state / truncation Termination = the episode ended naturally; truncation = a time limit cut it off.
Trace (see eligibility traces) —
Transition One interaction tuple (s, a, r, s′).
Trust region Constraining each update to stay close to the previous policy (TRPO's KL bound).
