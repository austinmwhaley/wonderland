Encoder vs the traditional process

The traditional path builds a wide customer table and fits a gradient-boosted model. The encoder path freezes one self-supervised model over the raw event stream and hands downstream heads a reusable state. Same holdout, same head, paired bootstrap intervals.

Three plugin families, one frozen artifact

The foundation is never retrained per task. Supervised heads predict; unsupervised heads explore geometry; RL heads estimate action response from pre-action state.
